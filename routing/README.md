# PCB F1 routing

The v6.0.3 apparent ground-trace break is a copper-pour visibility bug. The checked routing is continuous and retained. See the [diagnosis, dependency fix and regression results](../validation/TRACE-VISIBILITY.md).

F1 replaces the STM32 with RP2040, its flash, crystal and power support. The native autorouter could not produce clean copper for this dense two-layer placement. F1 therefore uses Freerouting 2.5.0 and explicit local power/clock routing, returned through TSCircuit’s documented `autorouter.algorithmFn` interface. The released core `0.0.2340` supplies the trace visibility fix.

`replay.ts` rejects any input that differs from the input used to generate the stored routing. Changed component geometry, net connectivity, rules or placement require rerouting and renewed checks. `verified.json` is a source asset, not an edit of compiled circuit JSON. It carries physical copper coordinates and real pad contacts.

The checked source build contains 1,277 trace records and 98 through vias (50 at 0.20/0.50 mm, 48 at 0.30/0.60 mm). Native placement/copper checks, plotted-copper shorts, exact supplier land/drill preservation, independent KiCad DRC, critical bypass/clock paths and bare-board/assembly identity all pass. The fresh source-derived fabrication export has zero DRC violations, zero opens and no per-violation exclusions. See [the validation report](../validation/REPORT.md). Fabrication export may refill/remove isolated ground pours but must preserve every routed trace and via.

To regenerate, export placement with `bun run export:placement`, obtain its actual routing-input SRJ, export that placement to KiCad and route against the project rules. KiCad's DSN `(type route)` wires must be normalized to Specctra `(type normal)` for Freerouting 2.5.0; keep intentionally fixed power/clock wires fixed. Run independent DRC, then use `import-kicad.py --help` to import the checked board and matching placement/input/report. The importer verifies all 222 physical pad centres and their source electrical nets. Each returned segment uses an existing source trace representing its real net; pad contacts reflect actual copper overlap. Rebuild and repeat every downstream check after importing.

Rules remain in `reference/fabrication-rules.json`: ordinary tracks and copper gaps at least 0.10 mm; component pads at least 0.15 mm; copper to edge at least 0.30 mm; ordinary vias 0.30 mm drill/0.60 mm pad, with 0.20 mm drill/0.50 mm pad for dense fanout. Both retain a 0.15 mm annular ring. The fine size remains above the published two-layer minimum in [JLCPCB capabilities](https://jlcpcb.com/capabilities/Capabilities). MCU bypass tracks use at least 0.15 mm. Through vias stay outside solder-paste lands.
